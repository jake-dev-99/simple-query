# simple_query_platform_interface

The platform interface for the [`simple_query`](https://pub.dev/packages/simple_query) federated plugin.

This package defines the contracts, data models, typed record classes, error types, and runtime validation that all platform implementations share. If you're building a custom platform implementation, depend on this package and implement `SimpleQueryPlatform`.

If you're just using `simple_query` in your app, you don't need to depend on this package directly.
